## 🚀 About

I build software close to the system boundary: **Linux services, concurrent C/C++ systems, robotics stacks, observability infrastructure, and AI-assisted developer tooling**.

My work is centered on making complex software **understandable, testable, observable, and reliable** — from low-level telemetry and network diagnostics to ROS 2 autonomy stacks and repository-aware coding agents.
